# Project Zomboid Mod Extractor

Script de batch para Windows que detecta automáticamente la instalación de Steam y copia los mods de Project Zomboid desde el Steam Workshop a la carpeta local de mods del usuario.

## Características

- Detección automática de la ruta de Steam en cualquier PC
- Soporte para múltiples ubicaciones de instalación de Steam
- Copia automática de mods del Workshop ID 108600
- Mantiene la estructura de carpetas de los mods
- Validación de rutas antes de la copia

## Uso

1. Ejecuta el script 
2. El script detectará automáticamente tu instalación de Steam
3. Los mods se copiarán a `%USERPROFILE%\Zomboid\mods` 

## Requisitos

- Windows
- Steam instalado
- Project Zomboid instalado
- Mods del Workshop descargados

# Project Zomboid Mod Extractor

Batch script for Windows that automatically detects Steam installation and copies Project Zomboid mods from Steam Workshop to the user's local mods folder.

## Features

- Automatic detection of Steam path on any PC
- Support for multiple Steam installation locations
- Automatic copy of mods from Workshop ID 108600
- Maintains the folder structure of mods
- Path validation before copying

## Usage

1. Run the `hola.bat` script
2. The script will automatically detect your Steam installation
3. Mods will be copied to `%USERPROFILE%\Zomboid\mods`

## Requirements

- Windows
- Steam installed
- Project Zomboid installed
- Workshop mods downloaded
